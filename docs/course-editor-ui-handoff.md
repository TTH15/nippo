# コース編集・単価設定 UI 引き継ぎ

更新: 2026-08-22 15:11 JST

## 現在地

B4「一体型フロー」案を採用し、コース編集モーダルと `CourseRateEditor` へ実装済み。
DB・API・migrationは変更せず、既存の保存形式と税計算を維持したUI変更。

実装後のブラウザ確認だけ未実施。Codex Desktop Appのブラウザで続きを確認する。

## 実装内容

### 基本情報

- コース名をモーダル上部で直接編集
- キャリアと取引先を横並び
- 略記・標準人数・色を次の段へコンパクトに配置
- 単価カードの横幅を確保するため、編集モーダルを `max-w-7xl`、内部を `max-w-6xl` へ拡張

### 単価設定

- 売上・支払を独立した大きな編集カードに変更
- `lg` 以上では取引先→売上→自社→支払→ドライバーの資金レールとFont Awesomeアイコンを表示
- `lg` 未満では資金レールとアイコンを非表示にし、売上・支払カードを縦積み
- 「計算方法」のselectを廃止
- 日当・個数単価を独立したチェック項目に変更。両方ONなら従来の `BOTH` へ保存
- 税抜・税込を横並びにし、契約上の税区分側だけ入力可能、反対側は自動換算表示
- サイクル別日当、全サイクル稼働時の日当、unit別個数単価、最低個数保証を維持
- 税区分を変更するときの既存確認ダイアログと、税抜集計値＋契約原額の保存方式を維持

1. `/admin/courses` を開き、日当＋個数単価があるコースの「単価設定」タブを表示
2. デスクトップ幅で、資金レール・取引先・自社・ドライバーのアイコンと2カードの重なりを確認
3. 画面幅を `lg` 未満へ狭め、レールが消えて売上→支払の縦積みになることを確認
4. 日当・個数単価のチェックを個別に切り替え、該当欄だけが現れることを確認
5. 税抜・税込を切り替え、確認ダイアログ、入力側、自動換算側、保存後の再読込を確認
6. サイクルが2つ以上あるコースで、全日日当・C1/C2・unit別単価が崩れないことを確認
7. 基本情報タブで、ヘッダー直接rename、キャリア/取引先、略記/人数/色の配置と自動保存を確認

## 見直し候補

- 資金レールの矢印は現在CSSの横線で、明示的な矢印先端はまだない。実画面で方向が弱ければFont Awesomeの矢印かCSS疑似要素を追加
- `TaxAmountPair` は税区分カード全体をクリックして切り替える。既存値がある場合は確認ダイアログが出る
- 全サイクル日当はnullableな上書き値のため、通常の日当とは異なり税抜・税込ペア表示にまだ統一していない
- 粗利は単位が異なるため、現実装の編集カードには無理に合算表示していない。日当粗利・個数粗利を出す場合はサイクル/unit名を明記する
