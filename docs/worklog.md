# 作業ログ（索引）

Claude Code の Stop フック（`~/.claude/bin/worklog-check.sh`）により、ファイル変更を伴う
ターンの終了時にエントリを追記する。

## 運用

- 本文は**月別ファイル** `docs/worklog/YYYY-MM.md` の末尾に追記する（月が変わったら新規作成）
- あわせて**この索引の「直近のエントリ」にも1行足す**。
  Stop フックは `docs/worklog.md` の mtime を見ているため、索引を更新しないと追記が検知されない
- 読むときは**全文を読まない**。`grep -n '^## ' docs/worklog/YYYY-MM.md` で見出しと行番号を
  一覧してから、必要な節だけ `offset` / `limit` で読む
- 「今どうなっているか」を知りたいだけなら worklog ではなく `docs/` 配下の正本
  （`money-handling-current.md` / `database-schema.md` など）を読む
