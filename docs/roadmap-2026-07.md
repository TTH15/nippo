## トラック一覧

### A. シフト業務の作り替え（web・最優先）
- [x] **A1: 配車とシフト編集の権限切り分け** ✅ 2026-07-20 — `can_dispatch` を新設し
      車両割当を `POST /api/admin/shifts/vehicle` に分離（vehicle-loans も can_dispatch 化）。
      シフト upsert から vehicle_id を除去（ドライバー解除時のみ連動クリア）。
      migration 105 で can_manage_shifts 保持ロールへ can_dispatch を付与（挙動維持）。
      UI はセル単位で出し分け: コース割当=can_manage_shifts / 車両・貸出=can_dispatch、
      配車のみの担当は割当済みセルだけ編集ポップオーバーを開ける。
- [x] **A2: コース／シフトの時間モデル** ✅ 2026-07-20 — 合意: 標準時間はコースごとに一定
      （曜日別パターンなし）→ courses に default 列 meeting_place / meeting_time / arrival_time /
      end_time、shifts に同名の上書き列（NULL=コース標準、実効値 = shifts.* ?? courses.*）。
      migration 106。コース設定モーダルに標準時間・集合場所の入力、シフトのセル編集モーダルに
      実効値の表示＋日別上書き（POST /api/admin/shifts/times、can_manage_shifts。
      「コース標準に戻す」で上書き解除）。セルのコースツールチップにも標準時間を併記。
      **残り: ドライバー画面（/api/me/shifts 系）への時間表示は未**（mobile 刷新時 or A3 で）。
- [ ] **A3: シフト画面のUI改善（洗い出し 2026-07-20 実施）** — Quick win 4件は同日対応済み:
      ①今日の列へ自動横スクロール ②未割当一覧の中央モーダル化（アンカー式ポップオーバー全廃）
      ③便指定休バッジ拡大（9→11px） ④~~セル編集モーダルの車両リストから貸出中トグル~~
      →**撤回**（車両選択＝その人に割り当てる車を選ぶ文脈に貸出設定は合わない、との判断）。
      代わりに貸出表（車両×日）を**押しながらなぞって一括設定**に対応（ON時に割当済みセルは
      スキップ＋まとめて通知）。貸出まわりのUIは今後改めて設計する。
      あわせて**叩き台生成（ルールベース）を廃止**（UI・API とも削除。シフト自動作成は C の
      AI 駆動・制約充足として再実装する方針）。
      入力効率系も同日対応済み: **D&Dコピー**（割当セルをドラッグ→同一ドライバー行は範囲フィル・
      別ドライバーは単セルコピー。希望休/担当外/定員満は自動スキップ＋まとめて通知。車両・時間上書きは
      コピーしない）＋**コース軸ビュー**（ヘッダーで軸切替。行=コース・セル=割当ドライバー、
      セルクリックでコース×日モーダル＝担当可能ドライバーの追加・解除）。
      ※空き枠バッジ（日付ヘッダー「空きN」）は一度入れたが**毎日走らないコースがあり定員基準の
      空きはノイズ**とのフィードバックで撤去（コース軸ビューのセル内に控えめ表示のみ残す）。
      表示系も同日対応済み: **表示密度3段切替**（簡易=コースのみ/標準=＋車両/詳細=＋実効集合時刻。
      localStorage 記憶）＋**手動リフレッシュボタン**（他管理者の変更を取り込む。自動再検証は
      楽観更新と衝突するため手動のみ）。A3 の洗い出し分はこれで全消化 — 以後は運用フィードバック起点。
- [ ] **A4: 場所マスタ・マップ連携** — A2 の meeting_place(自由テキスト)を org_places マスタへ昇格:
      name / kind(集合・駐車・倉庫…) / address / lat・lng / map_url。courses・shifts は ID 参照＋
      テキスト併存で段階移行。マップはまず共有リンク方式(APIキー不要、モバイルはネイティブマップが
      開いてナビ可)。駐車場所の登録・車両との紐づけもこのマスタに載せる。埋め込み地図/ジオコーディングは
      実需が出てから(Maps API 従量課金)。

      AI 駆動の制約充足（希望休・担当可能コース・定員・時間モデル）として実装する。
