# 地図作戦盤の使い勝手 再設計（2026-09-08 監査に基づく）

2026-09-08。ユーザーの主訴は「圧倒的に見づらい」「検索がしづらい」「車の移動がしづらい」「札が検索窓より前に出る」。隔離プレビュー（`/preview/admin/map`・normal／large・1440px と 375px）を Playwright で実操作した監査と、`page.tsx`（3,688 行）の棚卸しをもとに、原因と直し方を段階に分ける。設計の上位方針は [map-board.md](map-board.md)・[map-ux.md](map-ux.md) を維持する（地図をリストで割らない、予定の正本はシフト、位置は `vehicle_positions` に追記）。

## 2. 重なり順の規約（この画面の憲法にする）

地図コンテナ内の stacking を1か所（`apps/web/src/lib/map/zIndex.ts` の定数）に集約し、Marker の `zIndex` と Tailwind の `z-[...]` を全てそこから引く。

| 層 | z | 中身 |
|---|---|---|
| 0 | 0 | Mapbox canvas（3D モデル・面レイヤー・灯火はここ） |
| 1 | 1 | 拠点ピン |
| 2 | 2 | 縮退ドット（束の他車）。**札より下** |
| 3 | 5 | ナンバー札（クラスタの「N台」は札の内側） |
| 4 | 6 | 位置修正のつまみ／下書きピン／検索ヒットピン |
| 5 | 30 | 車両 popup（Mapbox Popup） |
| 6 | 40 | 地図上の操作 UI（ツールバー・検索窓・チップ・再検索・各パネル・凡例・バナー） |
| 7 | 50 | モーダル（`fixed`） |

- 操作 UI のラッパは `pointer-events-none`、押せる子だけ `pointer-events-auto`。余白は地図に抜ける。
- 375px は「再検索」を検索窓の直下（同じ列）に置き、ツールバーの行と競合させない。
- popup（30）は操作 UI（40）より下。popup が検索窓に隠れるときは既存の自動パンで避ける（札の上に開く方針は維持）。

## 3. 段階と内容

### 段階 1「見える」（監査 P1／P2 を潰す。小〜中・先に本番へ）

1. §2 の z-index 規約を導入し、P1-1・P2-4・P2-5 を同時に直す。
2. `declutterPlates` の衝突判定にドット（直径＋余白）とバッジの矩形を含める。バッジを札の内側（右上角の内側）へ移し、ドットは札より下の層へ。束の札クリックは常にグループ popup（メンバー全員）を開く。
3. 車体の見かけサイズにズーム下限を入れる。**z13 未満はモデルとリングを出さず、札＋ドットだけ**。z13〜15 は 40px→目標へ線形に上げ、z15 以上で現行の短辺 14%（クランプ 40〜120px）。`vehiclePresentation.ts` に `modelVisibleAtZoom(zoom)` と `targetLengthForZoom` を足し、コメントを実装に合わせる。
4. 拠点ピンは既定で表示（`showPlaces` の初期値 true。設定に保存されていればそれを優先）。
5. 拠点編集の draggable: `editingPlace` の変化で対象マーカーだけ `setDraggable(true)` を呼ぶ（全マーカーの作り直しはしない）。
6. Esc で popup・モーダルを閉じる。モーダルに `role="dialog"`・初期フォーカス・focus trap（既存 `ConfirmDialog` の実装があれば流用）。マーカーの `aria-label` を「大阪 481 わ 58-54 稼働中」のように付ける。
7. 検索ヒットのマーカーは hover で再生成しない（hover は CSS クラスの切替に変える）。

### 段階 2「探せる」（中）

- 検索窓を**1つのまま**、入力に対して 2 系統を同時に返す。上段「車両・ドライバー」（ローカル。ナンバーの数字4桁・かな・車種・ドライバー名の部分一致、位置なし車両も含む）、下段「住所・施設」（Mapbox。既存）。
- 車両ヒットを選ぶ → flyTo（z16）＋ popup を開く。位置なし車両を選ぶ → そのまま「地図をクリックして置く」に入る（既存 `pendingPlaceVehicle`）。
- ショートカットのチップ（ガソリン等）は「拠点を追加」の文脈でしか使わないので、検索窓にフォーカスした時だけ出す（帯を常設しない）。
- 375px は検索窓を1行に絞り、結果は地図の上に重ねるシート（地図を割らない）。

### 段階 3「動かせる」（中〜大・設計要確認）

現行の「位置修正モード → つまみ」は「全車のつまみを一度に出す」ため大量時に破綻する。**通常表示の札をそのまま動かす**方式に変える。

- `can_dispatch` を持つ人は、札を**長押し（PC はドラッグ開始）**でその1台だけ掴める。掴んだ札は z を上げ、他の札は薄くする。地図のパンは掴んでいる間だけ止める。
- 離した位置で確認シート（画面下・地図を割らない）:「大阪 481 わ 58-54 を **豊中センター（A-2）** に置きます」。拠点の半径内なら拠点・区画へスナップして名前を出す。外なら座標のまま「登録外の場所」。
- シートのボタンは2つ。**「今ここにある」**（`vehicle_positions` に `source='manual'` を追記。既存 `POST /api/admin/map/positions`）と **「ここへ運ぶ手配にする」**（既存の移動フォームを出発地＝現在地・届け先＝ドロップ先で開く）。「元に戻す」は直前の位置をもう1行追記（[map-board.md](map-board.md) §3-2）。
- 位置修正モードは「位置なし車両を置く」専用に縮小し、つまみの一斉表示はやめる。
- 履歴モード・閲覧のみ（`viewer`）ではドラッグ不可。共有ビューに手動配置を broadcast するのは後段。
- **要確認**: 長押しの秒数（既定 350ms）、ドロップ先の確認を省略できる設定を持つか（誤操作の方が痛いので持たない案）。

### 段階 4「読める」（中・3D 資産）

- 3D モデルの面に実ナンバーを貼る。プレビュー `map-operations` の `PLATE_MODEL_LAYER_ID`（車両ごとのプレート GLB 層）と `mapPlateImage`（SVG グリフ）を本番へ移す。生成は車両登録時にサーバーで1回（[map-board.md](map-board.md) §12 の未実装分）。近接（z17 以上）で札を消し、モデルのナンバーだけにするかは実機で判断。
- 同一点に重なる車の横ずらし（区画があれば区画へ、無ければ 1.2 台分ずつ横へ）。
- 未出勤のゴーストピン・要対応ストリップ・ワンタップ電話（[map-ux.md](map-ux.md) §2-1）は段階 4 の後。

## 4. 構造の整理（段階 1 と並行して少しずつ）

`page.tsx` は 3,688 行・useRef 28 本・useEffect 18 本。機能追加のたびに衝突するので、切り出しは「触る場所から」行う。

- 先に切る: z-index 定数、`declutterPlates` の束判定（画面座標を渡す純粋関数＋テスト）、`vehiclePresentation` のズーム下限（テストあり）。
- 次に切る: 検索（`useMapSearch`）、拠点の追加・編集（`usePlaceEditor`）、車両札の反映（`useVehicleMarkers`。作り直しではなく id ごとの差分更新に変える。プレビューに前例あり）。
- 型 `MapVehicle`／`MapPlace` を `lib/map/types.ts` に出し、API と共有する（`parkedElsewhere` を画面が読んでいない食い違いもここで解消）。

## 5. 検証

- 隔離プレビュー `/preview/admin/map?scenario=large` を段階ごとの受け入れ基準にする: 札の中心をクリックしてその束の popup が開く率 100%、検索窓のクリックで必ずフォーカスが入る、z10 で市名が読める、375px で上部の帯をドラッグして地図が動く。
- Playwright の再現手順（監査のスクリーンショット一式は scratchpad にあり、リポジトリには置かない）を `scripts/previews/` の巡回手順に追加する（roadmap-2026-09 A-3）。
- 本番は段階 1 をまとめて1回でデプロイし、段階 2 以降は機能ごと。

## 6. 決めておきたいこと

1. モデルを出すズームの下限（本書は z13）。広域を「札＋ドットだけ」にしてよいか。
2. 段階 3 の「札を直接ドラッグ」を採用するか（位置修正モードを残すか）。
3. 段階 2 の車両検索で、ドライバー名の検索を `can_view_members` に限るか（名簿と同じ扱い）。
4. 3D 面の実ナンバー（段階 4）を段階 2 より先にやるか。見た目の満足度は高いが、使い勝手の主訴には直接効かない。
