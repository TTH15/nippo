# コース編集 UI 案

2026-08-22 時点の比較用モックアップ。実装前の検討資料であり、アプリからは参照しない。

## 共通方針

- モーダル上部のコース名をクリックして直接変更する
- 基本情報は「キャリア・取引先」「略記・人数・色」の2段に圧縮する
- 税抜・税込は常に並べ、契約上の入力側だけ編集可能にする
- 計算方法はセレクトボックスを使わない

## 案

1. `option-a-dual-amount.png` — デュアル金額。現在の構造に最も近く、変更量が少ない
2. `option-b-contract-builder.png` — 契約ビルダー。設定の順序が明確で、初見でも理解しやすい（推奨）
3. `option-c-rate-matrix.png` — 単価マトリクス。複数の売上・支払条件を一覧比較しやすい
4. `option-b2-flow-builder.png` — B案を磨いたお金の流れ。日当・個数を独立選択し、税区分と粗利を単位ごとに明示（新推奨）
5. `option-b3-money-rail.png` — 取引先・自社・ドライバーを資金レールで結び、売上・支払カードを重ねた案。税抜・税込は横並び（最新案）
6. `option-b4-integrated-flow-cards.png` — 大きな売上・支払編集カード自体を資金レール上に配置し、上段の要約カードを廃止した一体型（最新推奨）
