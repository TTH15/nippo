- 左は枠線の「撮り直す」、右は黄色の「この写真を使う」。車体4方向・メーター・警告時・最終確認で位置と強弱を維持する。
- 最終確認は左「最初から撮り直す」、右「送信して／稼働開始・終了（または移動開始・終了）」。狭幅でも単語が途中で切れないよう、最終確認は意図的な2行にする。撮り直し対象/送信処理/写真の保持は従来どおり。
