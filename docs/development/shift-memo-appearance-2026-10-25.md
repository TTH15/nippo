# シフトメモの稼働日数・背景色・出力（2026年10月25日）

今回の実装は本番未反映。シフト・日報の前回リリースとは別の変更。

## 再利用元と変更

- 本番 `/admin/shifts` の `PersonalShiftMemoBoard.tsx` を改修し、既存の個人localStorage・共有 `useSharedBoard`、PNG生成・`pngToPdf` を継続使用。元からある未コミットの受け渡し・共有同期・business境界の変更は保持し、今回の対象だけを追記。
- 名前札に表示期間の稼働日数を併記し、「稼働日数」で全員を一覧表示。同じdriverIdの同日配置は別便・別枠・旧personKeyでも1日。非稼働セルは除外。非表示のコースも含む全コースの配置を数え、表示期間外・消滅したコースを除外する。文字札はpersonKeyで区別。正式シフトや日報実績を数え直す機能ではない。
- 「背景色」で選択日だけ／毎週同じ曜日を選び、白・黄・赤・青・緑・紫を指定。日付が曜日より優先し、白も明示指定。「曜日の色に戻す」で日付指定だけを解除。既存の休み・必要人数・配置は変えない。
- 個人/共有/JSONの受け渡しに任意の `backgroundColors` を追加。キーは `date:YYYY-MM-DD` / `weekday:0..6`、値は許可した6トークンだけ。同じ指定だけを競合判定し、別の指定は既存のmap単位同期で併存する。競合では色名を日本語表示。閲覧・経理は共有色を変更できず、日数を開いて確認できる。
- 出力は親コースの全幅見出しを除き、担当枠の左上にコース名を小さく表示。同名の枠名は出力時だけ重複を省き、担当枠間の横線も出力時だけ透明化。日付の縦線、C1/C2・配置・不足は保持。色も同じPNGに入り、そのPNGをPDFへ格納する。
- フォントを待ってから生成し、期間・配置・色・表示対象・幅が変わったときは生成済みデータを失効。古い非同期生成結果も採用しない。CustomSelectの選択メニューでは日付の選択を外さない。

## プレビュー

```bash
npm run preview:admin -- admin --port 3200
```

- http://127.0.0.1:3200/preview/admin/shifts?scenario=memo-colors&role=admin → シフトメモ。個人・共有に架空の配置と曜日/日付色を用意。同じ人のC1/C2配置が7日×2枠でも7日と表示される。
- `shared-conflict` は色の競合も有効な色トークンで再現し、「自分の変更を保存」で解決できる。`shared-save-error` は最初の保存だけ失敗し、既存同期処理の再取得・再送で復旧する。
- 架空データのみ。外部API、認証、DB、通知、Realtimeから隔離。プレビューの再読み込みはシナリオ初期値へ戻すため、実際の保存永続化はコンポーネントテストと隔離DBで検証。
