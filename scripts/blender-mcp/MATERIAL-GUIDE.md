# 軽バンの塗り分け手順（Blender 未経験者向け）

> **⚠️ この手順はもう使わない（2026-08-20）**
>
> 塗り分けは `build_vehicle.py` の `classify_by_texture()` が**自動でやる**ようになった。
> Meshy の texture 版原本はテクスチャに塗り分けが焼かれているので、面の UV で色を引けば
> 部位が分かる。手作業は不要。
>
> そもそも**この手順は最初から動かなかった**。中心にある「平坦な面を選択」は面の連結性に
> 依存するが、減面後のモデルは辺の 5〜6 割が境界で繋がっていない（12,000面が 7,737 個の
> 断片に割れる）。当時それに気づかずに書いた。
>
> 経緯と現行の手順は `docs/vehicle-3d-handoff.md` を参照。以下は記録として残す。

`keivan_from_scan.py` が下準備まで済ませてあります。**残っているのは窓を黒くすることと、
はみ出しの手直しだけ**です。慣れれば1車種10分ほどです。

## 開く

```
open ~/Developer/assets/hakotora-3d/keivan/keivan_work.blend
```

開いたら最初に **`Z` を押して「マテリアルプレビュー」を選ぶ**（色が見える表示になります）。
上部のシェーディング切替アイコン群の左から3番目でも同じです。

視点操作（マウスに中ボタンが無い場合は、環境設定 → 入力 → 「3ボタンマウスを再現」を ON に
すると `option`＋ドラッグで回せます）:

| したいこと | 操作 |
|---|---|
| 回す | 中ボタンドラッグ |
| 平行移動 | `shift` ＋ 中ボタンドラッグ |
| 拡大縮小 | ホイール |
| 正面／横／上から | テンキー `1` / `3` / `7` |

## 済んでいること

- 全長 3.395m・原点は底面中心・幅も実車比に補正済み
- 200万三角形 → **39,838 三角形**に減面（見た目は原本とほぼ同じ）
- マテリアル5種を作成済み: `keivan_body`（白）/ `keivan_glass`（黒）/ `keivan_tire`（黒）/
  `keivan_rim`（銀）/ `keivan_plate`（黄）
- タイヤとリムは**おおむね**塗り分け済み
- **折れ目に「シャープ」の印**を付けてあります。これが次の手順の要です

## やること1: 窓を黒くする（メイン作業）

窓は8枚（左右の側面3枚ずつ＋フロント＋リア）。現状ほとんどが車体色のままです。

1. マウスを車体に乗せて **`Tab`** → 編集モードに入る
2. **`3`** を押す → 面選択モード
3. **`option`＋`A`** で一度すべての選択を解除
4. 黒くしたい窓の**内側の面をどれか1つクリック**
5. メニュー **選択 → 拡張縮小 → 平坦な面を選択**
   （英語UIなら Select → Select Linked → Linked Flat Faces）
6. 画面左下に出る小さなパネルを開き、**「鋭敏さ」のスライダーを 25〜35度あたりで調整**する。
   窓の内側だけが選ばれ、車体にはみ出さない値を探します
   - ★はみ出したら角度を下げる／足りなければ上げる
7. 右側のプロパティで**マテリアルのタブ（球のアイコン）**を開き、リストから
   **`keivan_glass`** を選んで、下の **「割り当て」** ボタンを押す
8. 4〜7 を窓の数だけ繰り返す（反対側は視点を回して同じことをします）

うまく選べない窓は、`B` を押してから**ドラッグで四角く囲う**（ボックス選択）でも構いません。
その場合は先に **`option`＋`Z`** で透過表示を切ると、裏側の面まで一緒に選ばずに済みます。

## やること2: はみ出しの手直し

タイヤの自動塗り分けが、**フェンダー内側に黒い楔状のはみ出し**を残しています
（生成モデルの法線が一部反転しているのが原因で、自動では取り切れませんでした）。

1. 編集モードのまま、その黒い面をクリックで選ぶ（`shift`＋クリックで追加選択）
2. マテリアル一覧で **`keivan_body`** を選び、**「割り当て」**

逆に、タイヤなのに白いままの面があれば `keivan_tire` を割り当ててください。

## やること3（任意）: ナンバープレートとライト

- ナンバープレートは前後の凹んだ長方形。同じ手順で `keivan_plate`（黄）を割り当て
  - 事業用（黒ナンバー）にしたい場合は、マテリアルの色を後から変えれば全車に効きます
- ヘッドライト・テールランプも同様に分けられますが、資料用途では省いても違和感は出ません

## 保存と書き出し

- **`cmd`＋`S`** で上書き保存
- 静止画に使うだけなら、この .blend のままで構いません
- 地図に載せる低ポリが要るときは、この状態から減面率を上げて書き出します（別途対応します）
